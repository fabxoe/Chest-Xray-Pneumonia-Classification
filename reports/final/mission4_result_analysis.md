# Mission 4. 결과 분석

## 1. Before vs After 비교

초기 SimpleCNN baseline은 리더보드 `0.81891`을 기록했다. 이후 ResNet18 fine-tuning으로 `0.9278846154`, ConvNeXt-Tiny로 `0.94711`, OOF stacking 계열로 `0.955` 이상까지 개선되었다. 최종 결과는 `0.9663461538`, 최종 순위는 `6위`였다.

| 구분 | 모델/전략 | 리더보드 점수 |
|---|---|---:|
| 초기 baseline | 개선 SimpleCNN | 0.81891 |
| 전이학습 baseline | ResNet18 | 0.9278846154 |
| 강한 단일 CNN | ConvNeXt-Tiny | 0.94711 |
| OOF 기반 조합 | ConvNeXt + EfficientNet 계열 | 0.955~0.958 |
| 최종 결과 | 최종 제출 | 0.9663461538 |

## 2. Confusion Matrix 해석 기준

Validation에서는 accuracy뿐 아니라 confusion matrix를 함께 확인했다.

- TP: 폐렴 이미지를 폐렴으로 맞춘 경우
- TN: 정상 이미지를 정상으로 맞춘 경우
- FP: 정상 이미지를 폐렴으로 예측한 경우
- FN: 폐렴 이미지를 정상으로 예측한 경우

의료 이미지 분류에서는 FN이 특히 중요하다. 폐렴 환자를 정상으로 판단하면 후속 진료가 지연될 수 있기 때문이다. 반대로 FP는 불필요한 추가 검사로 이어질 수 있지만, FN보다 임상적 위험은 상대적으로 낮을 수 있다.

## 3. 실패 사례에서 확인한 패턴

### 3.1 Epoch 증가

ResNet18에서 epoch를 늘렸을 때 validation accuracy는 유지되었지만 리더보드 점수는 하락했다. 이는 더 오래 학습하는 것이 항상 일반화 성능 개선을 의미하지 않음을 보여준다.

### 3.2 Fine-tuning 범위 확대

layer3까지 학습 범위를 넓힌 실험도 성능이 하락했다. 작은 데이터셋에서는 너무 많은 파라미터를 업데이트하면 pretrained feature가 흔들릴 수 있다.

### 3.3 Augmentation

좌우 반전과 TTA는 일부 validation 결과에서는 도움이 될 수 있었지만, X-ray에서는 좌우 방향 정보가 의미를 가질 수 있다. 따라서 의료 영상 augmentation은 일반 이미지 분류처럼 무조건 강하게 넣기보다, 임상적으로 말이 되는 변환인지 검토해야 한다.

### 3.4 입력 크기 확대

384 입력 no-flip ConvNeXt는 fold0 기준으로는 성능이 좋아졌지만, 5-fold와 최종 조합에서는 항상 유리하지 않았다. 이미지 크기 확대는 세부 정보를 더 보존할 수 있지만, 모델이 더 많은 주변 정보나 촬영 표식에 반응할 가능성도 함께 생긴다.

## 4. 모델별 오류 양상

ResNet18은 상대적으로 FN을 줄이는 방향의 예측을 보였고, ConvNeXt는 더 강한 단일 모델 성능을 보였다. EfficientNet-B0는 단독 성능은 낮았지만 일부 조합에서 보완 정보로 사용되었다. 이 차이는 단일 모델만 선택하는 것보다 OOF 기반 조합을 시도한 이유가 되었다.

## 5. 핵심 인사이트

모델 개선은 단순히 더 큰 모델을 쓰거나 더 오래 학습하는 문제가 아니었다. 실제로는 오류 양상, 클래스 불균형, augmentation의 타당성, validation과 테스트 분포 차이를 함께 고려해야 했다. 실패한 실험들은 다음 전략을 선택하는 기준을 제공했다.
