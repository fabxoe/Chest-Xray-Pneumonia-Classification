# Mission 5. 모델 해석 및 서비스 확장 설계

## 1. Grad-CAM을 사용한 이유

Grad-CAM은 CNN 계열 모델이 특정 class를 예측할 때 어느 영역에 더 강하게 반응했는지 시각화하는 방법이다. 의료 이미지 분류에서는 단순히 예측값만 보는 것보다, 모델이 어떤 영상 영역을 근거로 삼았는지 확인하는 과정이 중요하다.

주의할 점은 Grad-CAM이 실제 병변 위치를 증명하지는 않는다는 것이다. 따라서 보고서에서는 “병변을 정확히 보았다”가 아니라 “해당 영역에 더 강하게 반응했다”라고 해석한다.

## 2. XAI 분석에 사용한 자료

다음 분석을 활용했다.

- ConvNeXt disagreement 이미지에 대한 Grad-CAM과 LIME 비교
- ResNet, DenseNet, EfficientNet, ConvNeXt의 다중 모델 Grad-CAM 비교
- validation FP/FN 후보 분석
- OOF disagreement Grad-CAM 비교
- 384 no-flip ConvNeXt와 기존 ConvNeXt의 CAM 비교

## 3. 주요 해석 결과

### 3.1 Grad-CAM과 LIME 비교

Grad-CAM은 모델의 마지막 convolution feature map을 바탕으로 class별 반응 위치를 보여주고, LIME은 입력 이미지를 작은 영역으로 나누어 예측에 영향을 주는 영역을 근사한다. 두 방법을 같이 보면서 모델이 특정 위치에만 과도하게 반응하는지 확인했다.

### 3.2 모델별 반응 위치 차이

OOF disagreement Grad-CAM 분석에서 ConvNeXt와 ResNet은 같은 이미지에서도 class 1에 대한 반응 위치가 달랐다.

- CAM pixel correlation 평균: `0.251`
- CAM 상위 20% 영역 IoU 평균: `0.216`

두 값이 낮다는 것은 두 모델이 같은 예측 문제에서도 서로 다른 영역에 반응했을 가능성을 의미한다. 이는 앙상블과 stacking이 단순 평균 이상의 의미를 가질 수 있는 근거가 되었다.

### 3.3 Validation 오류 해석

Validation FP/FN 분석에서는 모델이 틀린 경우를 따로 확인했다. 특히 FN은 실제 폐렴을 정상으로 판단하는 오류이므로 의료 서비스 관점에서 더 위험하다. 모델 성능을 accuracy로만 판단하지 않고, 오류 종류를 분리해서 보는 것이 필요했다.

## 4. 서비스 확장 시 저장할 데이터 정의

실제 서비스로 확장한다고 가정하면, 모델 결과를 다음과 같이 저장할 수 있다.

| 저장 데이터 | 코드상 생성 위치 | 의미 |
|---|---|---|
| 원본 이미지 경로 | Dataset의 `__getitem__` 또는 inference 입력 | 사용자가 업로드한 X-ray 원본 |
| 예측 label | `argmax` 또는 threshold 적용 후 | 정상/폐렴 예측 결과 |
| 예측 확률 | `softmax` 또는 class 1 probability | 모델의 확신 정도 |
| Grad-CAM 이미지 | Grad-CAM 생성 함수 | 모델이 강하게 반응한 영역 시각화 |
| risk level | probability 기반 위험도 산출 로직 | 사용자에게 보여줄 위험도 단계 |

## 5. Risk Level 예시

의료 보조 서비스에서는 민감도를 우선할지, 특이도를 우선할지에 따라 risk level 기준이 달라질 수 있다. 예시는 다음과 같다.

| class 1 probability | Risk Level | 의미 |
|---:|---|---|
| 0.00~0.40 | Low | 폐렴 가능성이 낮다고 판단 |
| 0.40~0.70 | Medium | 추가 확인이 필요한 불확실 구간 |
| 0.70~1.00 | High | 폐렴 가능성이 높아 우선 확인 필요 |

이 기준은 실제 의료 기준이 아니라 과제용 설계 예시이다. 실제 서비스에서는 병원 데이터, 전문의 검토, 민감도/특이도 요구사항을 반영해 threshold를 다시 정해야 한다.

## 6. 실제 서비스 적용 한계

- 학습 데이터와 실제 병원 데이터의 촬영 장비, 환자군, 전처리 방식이 다를 수 있다.
- Grad-CAM은 모델 반응 위치를 보여줄 뿐, 임상적 병변 위치를 확정하지 않는다.
- FN은 진료 지연으로 이어질 수 있으므로, 단독 진단이 아니라 보조 도구로 사용해야 한다.
- 예측 확률은 calibration이 충분하지 않으면 실제 위험도와 다를 수 있다.

## 7. 핵심 인사이트

의료 AI에서는 성능 수치뿐 아니라 모델이 어떤 근거로 판단했는지, 어떤 오류가 더 위험한지 함께 설명해야 한다. Grad-CAM과 LIME은 모델을 완전히 해석하는 도구는 아니지만, 모델의 판단 근거를 점검하고 서비스 적용 시 주의점을 찾는 데 도움이 되었다.
